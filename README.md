# 材質轉印　視覺評估問卷

線上問卷（GitHub Pages）。受試者從多張生成結果中選出最符合參考材質與目標圖形的一張。

## 內容

| | |
| --- | --- |
| `index.html` | 問卷本體 |
| `config.js` | 作答收集端點（Google Apps Script）|
| `items.json` | 116 題（三段）|
| `img/` | 題目影像，WebP |

## 三段

| 段 | 題數 | 形式 |
| --- | --- | --- |
| 一 | 46 | 六選一（含 2 題重複，作為一致性檢核）|
| 二 | 50 | 六選一 |
| 三 | 20 | 兩題式：相似度 5 點量表 ＋ 二選一 |

題目順序每位受試者隨機；選項位置固定但已打散，作答資料不含方法名稱。

## 開發

```bash
python -m http.server 8000   # 本機預覽
```

作答結果寫入 Google 試算表，接收端程式見專案內的 `main.gs`。
